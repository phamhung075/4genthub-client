# the operator skills spell the room placeholder

The three operator skills that document this client's own verbs taught the predecessor's argument
spelling: seven `<rig>` placeholders on seven lines, in `4genteam ps <rig>`, `4genteam seat reseat
<rig> --seat`, `4genteam up <rig> --team <dir>` and `4genteam continue <rig>`. Each is `<room>` now,
because the flags and positionals this client takes are `--room` and a room name: a verb this client
has may not be documented with a name it no longer accepts.

What stays: the ~12 mentions that name the predecessor on purpose - `room-runtime-switch`'s "not the
predecessor's `rig ps --nodes --room R --json` shape" and its teardown note, `seat-runtime-switch`'s
contrast sentence, `spawn-team`'s "NEVER launch or resume with the predecessor orchestrator's `rig
up`" plus `rig create`, `rig up <spec>.yaml`, `rig usage series` and `rig whoami`. A prohibition that
cannot name what it forbids is not a prohibition.

`grep '<rig>' skills/` is empty afterwards. No code changes; the skill text is the whole commit.
