# A seat does not raise the ceiling that bounds it

### Changed
- `internal/clientroom/limits.go`: `4genteam room limits` refuses a raise asked for by a SEAT. Measured on the real binary before this rule (a throwaway state dir, the caller a seat): `--usd 999` wrote 999 into the file and `--off` disabled the ceilings, so the seat a ceiling exists to stop was the one who could lift it. The refusal names the marker and the way out - a seat may LOWER a ceiling or turn the ceilings ON; the OWNER raises one, running the verb with $AGENTHUB_SESSION_NAME unset. `--off` is a raise only while the ceilings are ON, and a number the file does not carry yet is not a ceiling, so writing that one raises nothing: a room with no file can still be given its agreed 25/300 by whoever runs it.
- `internal/clientroom/limits.go`, `internal/clientroom/room.go`, `internal/roombudget/roombudget.go`: the strings I landed at 6b4db16 measured the guard BEFORE the park-semantics lane merged, and at main they were false - the repo's asset (`rust/agenthub-runtime/assets/seat-guard.ts`, blob 2e978d1) names the room's `limits.json` and the seat's `parked.json` in its protected paths and parses rm/unlink/truncate/shred, sed -i/perl -i and dd of= as write targets too. The reviewer's re-scope ask named the other half, and the measurement confirms it: the copy a seat RUNS is not that asset but the one the RUNTIME BINARY embeds and writes into `<seat dir>/hooks/pre/seat-guard.ts` when it prepares the seat (supervisor/mod.rs:272,641), and the installed binary (16:50Z, sha256 aced9217) still embeds the asset as of 194343c (blob d18048e5). All five seats' installed copies hash 47d24e58 and refuse only an edit tool's path, a redirect, tee and cp on limits.json and NOTHING on parked.json - so sed -i, rm, truncate and dd of= pass there until the runtime is rebuilt, installed and the seats restarted, and a RESEAT re-installs the same older copy. Every string names both copies, the reseat's real source and the residual both share: a path opened from INSIDE a program (python3 -c, node -e) or spelled through a variable.
